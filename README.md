Equicord userplugin that automates progression for Discord profile badges, including Game Time, Game Variety, Streaming, and HypeSquad.

## Features

### Game Time Badge
* Patches Discord `RunningGameStore` to report authentic running game processes from a curated database of 130 verified PC titles.
* Keeps continuous presence active so Discord tracks hours toward tiers from Casual (1 hour) up to Eternal (5,000 hours).
* Requires the Discord desktop application and "Display current activity as a status message" enabled under Activity Privacy.

### Game Variety Badge
* Rotates unique detectable PC games to progress toward the Universalist tier (100 unique games).
* Employs a 75-second rotation delay by default. Discord backend telemetry discards sessions shorter than 60 seconds.
* Supports manual game advancement and progress reset.

### Streaming Badge
* Monitors screen sharing sessions in voice channels and tallies active hours toward streaming milestones.
* Tracks participant count. Discord requires at least one other participant in the channel for hours to count.
* Provides Anti-AFK disconnect prevention to prevent idle timeouts during extended streaming sessions.

### HypeSquad Houses
* Assigns your account to House of Bravery, House of Brilliance, or House of Balance without taking the client quiz.
* Sends authenticated requests to the Discord `/hypesquad/online` endpoint to update the badge.

## Installation

1. Clone this repository into your Equicord `src/userplugins` directory:

```bash
cd Equicord/src/userplugins
git clone https://github.com/aboveproof/BadgeFarmer.git
```

2. Rebuild Equicord:

```bash
pnpm run build
```

3. Restart Discord (`Ctrl + R`).

4. Open User Settings > Plugins > BadgeFarmer to configure and monitor your badges. You can also run the `/badgefarm` slash command in any channel.

## Technical Implementation

* **Store Patching**: Hooks `RunningGameStore` methods (`getRunningGames`, `getVisibleRunningGames`, `getRunningDiscordApplicationIds`, `getGamesSeen`, `isDetectionEnabled`) to inject mock processes into Discord's native tracking pipeline.
* **Gateway Synchronization**: Dispatches `LOCAL_ACTIVITY_UPDATE` with a persistent socket identifier (`BadgeFarmer`) and active instance flags to push Opcode 3 presence frames to Discord Gateway.
* **Data Persistence**: Stores farmed hours, logged game IDs, and selected preferences inside Equicord `DataStore`.
